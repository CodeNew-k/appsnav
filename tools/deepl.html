译文为什么更顺

多数翻译工具按句子切分、逐段替换，结果是每句都通，整篇读起来断裂。DeepL 在上下文衔接上做了更多处理，代词指代、连接词、语气能前后一致。

欧语之间的互译是它的传统强项；中英互译这几年进步明显，技术文档、商务邮件这类文体完成度很高。

文学性文本仍是弱项。双关、方言、文化梗，机器翻译基本无能为力，得靠人重写。

文档翻译，比复制粘贴省事

直接上传 Word 或 PPT，它会保留原有版式输出译文。表格、页眉页脚、项目符号通常能保住，复杂的图文混排可能错位。

这是它比同类工具实用的地方：合同、方案、说明书这类带格式的文件，不用翻译完再重新排版。

译完必须逐页对照原文检查，尤其是数字、条款编号、专有名词。格式保住了不代表内容没出错。

术语表：专业文档的关键

同一个术语在同一份文件里出现三种译法，是机器翻译最常见的问题。术语表功能可以锁定译法：你规定“throughput 统一译为吞吐量”，全篇就不会变。

做法是把术语整理成表，上传后每次翻译都应用同一套规则。团队积累下来，译法就能保持一致。

术语表需要付费档位，个人偶尔翻译用不上；长期处理同类文档的团队，值得花时间建一份。

免费与付费的边界

免费版有单次字数上限，文档翻译数量有限，术语表不可用。订阅后放开字数、文档数量与术语表，并提升处理优先级。

API 按字符计费，适合接进内容管理系统做批量翻译。注意 API 与网页版的额度分开计算。

境内可以访问，但加载与上传速度不稳定，大文件建议在网络状况好的时段处理。

怎么用才不踩坑

  • 先给人看，再给机器翻。中文原文写得越清楚、句子越短，译文质量越高。
  • 拆长句。一句话套三个从句，任何翻译工具都会乱。
  • 保留原文结构。标题、列表、编号保留，译文的逻辑才不丢。
  • 译完回读一遍。只读译文，能发现机器看不出的别扭。

DeepL 常见问题

DeepL 免费吗？

免费版有单次字数和文档数量限制，术语表不可用；高频或专业用途需要订阅。

支持中文吗？

支持简体与繁体中文，中英互译质量在同类里靠前，技术类文本表现最好。

能翻译整份 Word 吗？

可以，上传后保留原有版式输出。复杂图文混排可能错位，译完要逐页核对。

术语表怎么用？

把专业术语与规定译法整理成表并上传，翻译时自动套用，保证全篇一致。需要付费档位。

译文能直接用吗？

内部沟通可以，对外发布建议人工过一遍。数字、条款、专有名词必须逐条核对。
