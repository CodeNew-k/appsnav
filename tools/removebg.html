它抠的是什么

自动识别主体与背景的边界，把背景变成透明。对人像、商品、宠物这类主体明确的图片，准确率相当高；对复杂边缘——头发、毛绒、纱质、玻璃——处理得比多数手动工具细。

它的算法不只是“识别轮廓”，还会估算半透明区域的 alpha 值，所以发丝边缘不会出现生硬的白边。这一点在深色背景换浅色背景时特别明显。

反过来说，主体不清晰、背景与主体颜色接近、画面有大面积反光时，结果会明显变差。

正确用法：先处理，再检查，再导出

  1. 用分辨率足够的原图。压缩过度的图，边缘信息已经丢了，抠出来必然毛糙。
  2. 上传后先看预览。免费预览是低分辨率，用来判断边缘质量够不够，不要直接拿去用。
  3. 用擦除/还原工具修局部。多抠进来的背景、被误删的主体部分，手动补两笔比重新上传快。
  4. 导出高清 PNG。需要付费额度。透明通道保留，放到新背景上不会有白边。
  5. 换背景后再检查一次。在浅色和深色底上各看一遍，边缘问题会立刻暴露。

哪些图它搞不定

效果通常很好
  • 单人半身像、证件照
  • 白底商品图
  • 宠物、毛发清晰的动物
  • 轮廓分明的物体
容易翻车
  • 透明材质、玻璃杯、纱裙
  • 主体与背景颜色接近
  • 多人重叠、肢体交叠
  • 运动模糊、逆光剪影

批量与接口

网页版单张处理，适合零散需求。批量上传需要付费套餐，一次几十张，常用于电商上新。

API 按张计费，返回透明 PNG。接进上架流程后，运营不用逐张手动处理。注意设置并发上限和失败重试，别把接口打成瓶颈。

也有 PS、Figma 的插件版本，设计流程里直接调用，省掉导出再导入。

隐私与版权

上传的图片会经过其服务器处理，免费预览通常以较低分辨率返回。涉及未公开的产品图、人物肖像，先确认是否有权处理与公开。

抠图本身不产生新的著作权，但把他人图片去背后用于商业宣传，仍可能侵犯原图权利。商用素材的来源要干净。

处理完可以在账号里删除历史图片，减少留存。

Remove.bg 常见问题

Remove.bg 免费吗？

免费可以预览低分辨率结果，下载高清图需要额度。批量与 API 按量付费。

抠出来的图有白边吗？

多数情况没有，算法会处理半透明边缘。深色底换浅色底时仍建议放大检查发丝部分。

支持批量处理吗？

网页版单张为主，付费套餐支持批量上传，大批量建议用 API 接入自己的流程。

能处理透明物体吗？

玻璃、纱质、水花这类半透明主体识别困难，结果常需要手动修补。

上传的图片会被保存吗？

会经过服务器处理，可在账号中删除记录。未公开的产品图与人物照片，上传前先确认授权。
